# About this fork

This repository is an independently maintained fork of [Teng Lin's notebooklm-py](https://github.com/teng-lin/notebooklm-py).

The fork exists because the upstream project already solves a substantial integration problem. Rather than recreate its Python client, CLI, MCP and REST surfaces, this project preserves that foundation and explores additional research-preservation, provenance, export-assurance and agent-interoperability capabilities.

## Acknowledgement

Thank you to Teng Lin for creating and maintaining the original project and for making that work available under the MIT licence. Upstream remains the canonical home of the original project. This fork is independently maintained and is not affiliated with Google or endorsed by Teng Lin.

## Independent direction

The fork's interests include:
- portable and loss-aware research archives;
- explicit distinctions between original uploads and indexed/extracted text;
- resource-level retrieval status and completeness reporting;
- integrity verification using checksums;
- optional AgentSON event integration.

These are roadmap areas, not a claim that every capability is already available.

## Working principles

Build on proven work; preserve attribution and licence notices; make extensions reviewable; report uncertainty honestly; keep privacy and user control central; and contribute generally useful fixes upstream where appropriate.
